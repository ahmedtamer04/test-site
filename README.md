# Date Ask 💌

Static site, no build step.

- Yes → big beating heart + falling hearts
- No → "Fuck you." (with a "let me try again" button)

## Personalize
- Edit `HER_NAME` at the top of `script.js`, or share the link as `https://your-site.vercel.app/?name=Sara`

## Deploy on Vercel
**Option A: CLI**
```
npm i -g vercel
cd date-site
vercel --prod
```
(Framework preset: "Other", no build command, output directory = root.)

**Option B: GitHub**
Push this folder to a repo, import it at vercel.com/new, click Deploy.

**Option C: Drag and drop**
Zip/drag the folder into vercel.com/new.
